# Casa Marea

A concept hotel landing page organized around a visitor's daily itinerary.

![Preview of the landing page](docs/preview.png)

## Overview

A concept hotel landing page organized around a visitor's daily itinerary. The layout adapts to desktop and mobile screens.

## Features

- Time-of-day and location views
- Interactive trip preferences and itinerary summary
- Responsive navigation and a native dialog

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Live Demo

https://dayiawan.github.io/casa-marea/

## Running Locally

Open `index.html` directly in a browser or serve the folder with `python3 -m http.server 8000` and open `http://localhost:8000/`.

## Notes

- This is a frontend concept: on-page calculations, configurations and briefs are demonstrations, with no production backend.
