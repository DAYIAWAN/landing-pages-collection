# MORPHO

A concept clinical interface presented as an interactive landing page.

![Preview of the landing page](docs/preview.png)

## Overview

A concept clinical interface presented as an interactive landing page. The layout adapts to desktop and mobile screens.

## Features

- Clinical system and information-layer selectors
- Accessibility controls and scenario views
- On-page route planner and demonstration pass dialog

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure


## Live Demo

https://dayiawan.github.io/morpho/

## Running Locally

Open `index.html` directly in a browser or serve the folder with `python3 -m http.server 8000` and open `http://localhost:8000/`.

## Notes

- This is a frontend concept: on-page calculations, configurations and briefs are demonstrations, with no production backend.
