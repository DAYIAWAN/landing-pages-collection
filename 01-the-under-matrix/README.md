# TheUnderMATRIX

An interactive directory for the MOTOYAMA project ecosystem.

![Preview of the landing page](docs/preview.png)

## Overview

An interactive directory for the MOTOYAMA project ecosystem. The layout adapts to desktop and mobile screens.

## Features

- Project direction selector and store category tabs
- Alphabetical index with live filtering
- Responsive navigation and section progress indicators

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```text
├── index.html
├── assets/css/style.css
├── assets/js/app.js
├── assets/img/
├── docs/preview.png
└── README.md
```

## Live Demo

https://dayiawan.github.io/the-under-matrix/

## Running Locally

Open `index.html` directly in a browser or serve the folder with `python3 -m http.server 8000` and open `http://localhost:8000/`.

## Notes

- No build step or package installation is required.
