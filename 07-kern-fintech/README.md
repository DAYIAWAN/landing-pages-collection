# KERN Fintech

A concept landing page for financial controls and payment workflows.

![Preview of the landing page](docs/preview.png)

## Overview

A concept landing page for financial controls and payment workflows. The layout adapts to desktop and mobile screens.

## Features

- Interactive workflow modes and scope selectors
- Range-based workload simulator
- Multi-step finance brief dialog

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Live Demo

https://dayiawan.github.io/kern-fintech/

## Running Locally

Open `index.html` directly in a browser or serve the folder with `python3 -m http.server 8000` and open `http://localhost:8000/`.

## Notes

- This is a frontend concept: on-page calculations, configurations and briefs are demonstrations, with no production backend.
