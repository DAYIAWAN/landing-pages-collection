# Service Maximum

An insurance services landing page with an illustrated editorial layout.

![Preview of the landing page](docs/preview.png)

## Overview

An insurance services landing page with an illustrated editorial layout. The layout adapts to desktop and mobile screens.

## Features

- Interactive audience tabs and service-route controls
- Service details in a native dialog
- Responsive navigation and scroll reveals

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```text
├── index.html
├── assets/css/style.css
├── assets/js/app.js
├── assets/img/
├── docs/preview.png
└── README.md
```

## Live Demo

https://dayiawan.github.io/service-maximum/

## Running Locally

Open `index.html` directly in a browser or serve the folder with `python3 -m http.server 8000` and open `http://localhost:8000/`.

## Notes

- No build step or package installation is required.
