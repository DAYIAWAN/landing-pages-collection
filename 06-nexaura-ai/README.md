# Nexaura AI

A concept landing page for an AI operations platform.

![Preview of the landing page](docs/preview.png)

## Overview

A concept landing page for an AI operations platform. The layout adapts to desktop and mobile screens.

## Features

- Product area tabs and interactive process lab
- Billing-period switch for displayed prices
- Pilot brief dialog and FAQ disclosure sections

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```text
├── index.html
├── assets/css/style.css
├── assets/js/app.js
├── assets/img/
├── docs/preview.png
└── README.md
```

## Live Demo

https://dayiawan.github.io/nexaura-ai/

## Running Locally

Open `index.html` directly in a browser or serve the folder with `python3 -m http.server 8000` and open `http://localhost:8000/`.

## Notes

- This is a frontend concept: on-page calculations, configurations and briefs are demonstrations, with no production backend.
