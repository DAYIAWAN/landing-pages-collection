# VANTA E7

A concept landing page for an electric grand tourer.

![Preview of the landing page](docs/preview.png)

## Overview

A concept landing page for an electric grand tourer. The layout adapts to desktop and mobile screens.

## Features

- Body-shape, drive-mode and finish selectors
- Interactive route and temperature controls
- Configuration brief dialog and responsive layout

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```text
├── index.html

```

## Live Demo

https://dayiawan.github.io/vanta-e7/

## Running Locally

Open `index.html` directly in a browser or serve the folder with `python3 -m http.server 8000` and open `http://localhost:8000/`.

## Notes

- This is a frontend concept: on-page calculations, configurations and briefs are demonstrations, with no production backend.
