# IRONTRACE

A concept industrial automation landing page with simulated production views.

![Preview of the landing page](docs/preview.png)

## Overview

A concept industrial automation landing page with simulated production views. The layout adapts to desktop and mobile screens.

## Features

- Equipment and digital-twin layer selectors
- Interactive load and fault-chain controls
- Scope configurator and project brief dialog

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```text
├── index.html
├── assets/css/style.css

└── README.md
```

## Live Demo

https://dayiawan.github.io/irontrace/

## Running Locally

Open `index.html` directly in a browser or serve the folder with `python3 -m http.server 8000` and open `http://localhost:8000/`.

## Notes

- This is a frontend concept: on-page calculations, configurations and briefs are demonstrations, with no production backend.
